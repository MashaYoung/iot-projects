# 🌡️ Climate Monitor for Pharma Warehouse

**Python-симуляция измерителя параметров микроклимата фармацевтического склада
на базе логики ESP32 + датчика DHT22.**

Оригинальная прошивка была написана на C (Arduino) в среде Wokwi и выполнялась
магистрантами программы «Интернет вещей и киберфизические системы»
(НИУ ВШЭ, МИЭМ). Этот репозиторий — переписанная на Python версия, которая
работает на обычном компьютере и в контейнере Docker, без реального «железа».
Симуляция повторяет логику прибора: суперцикл, опрос датчика, контроль
лимитов, «светодиоды», кнопку и журналирование.

```
        🌡️  🏭 PHARMA CLIMATE MONITOR  🏭  🌡️
   ┌─────────────────────────────────────────┐
   │  T: 22.4 °C        humidity: 47.1 %    │
   │  status: GREEN OK                      │
   └─────────────────────────────────────────┘
```

## Соответствие приказам Минздрава

- **Температура:** от **+10.0 °C** до **+30.0 °C** (Приказ №706н)
- **Относительная влажность:** не более **70 %** (Приказ №646н)

При нарушении пределов прибор взводит тревогу: загорается «красный светодиод»,
показания продолжают фиксироваться.

## Что симулируется

| Компонент оригинальной прошивки (C) | Реализация на Python |
|---|---|
| Датчик DHT22 на пине D15 | Функция `read_sensor()` — имитация «дыхания» значений |
| Кнопка BOOT на пине D4 | `handle_button()` — неблокирующий опрос клавиатуры |
| Зелёный / красный светодиод | `update_leds()` — вывод состояния в терминал |
| Суперцикл с шагом 100 мс | `superloop()` с `time.sleep()`, частотное деление |
| Журнал показаний | JSON-строки с меткой времени (`datetime`, `json`) |

> В реальной системе на ESP32 внутри `read_sensor()` данные читались бы
> напрямую с датчика:
> ```python
> # t = dht.readTemperature()
> # h = dht.readHumidity()
> ```

## Запуск локально (без Docker)

Требуется Python 3.10+.

```bash
python climate_monitor.py
```

По умолчанию кнопка BOOT активна: нажимайте Enter, чтобы запросить состояние
прибора. Чтобы отключить кнопку (например, на CI), задайте переменную
окружения:

```bash
BUTTON_ENABLED=0 python climate_monitor.py
```

## Запуск в Docker

Собрать образ:

```bash
docker build -t myclimate .
```

Запустить:

```bash
docker run --rm myclimate
```

Внутри контейнера кнопка отключена через `ENV BUTTON_ENABLED=0`, поэтому
в лог выводится только телеметрия. Флаг `-u` в команде запуска делает вывод
потоковым (без буферизации).
