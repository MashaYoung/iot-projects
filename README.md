# IoT-симуляции на Python (ESP32 → симуляция на ПК)

Портфолио учебных проектов магистерской программы «Интернет вещей
и киберфизические системы» (НИУ ВШЭ, МИЭМ), исходно реализованных на C
(Arduino / ESP32) и **переписанных на Python** для запуска на обычном
компьютере и в Docker.

Собрание независимых симуляций умных устройств и общей инфраструктуры Docker.

## 🌡️ Климат-монитор фармацевтического склада

Система непрерывного контроля температуры и влажности на базе ESP32 + DHT22
согласно приказам Минздрава РФ (№706н, №646н).

- **Критический температурный коридор:** +10.0…+30.0 °C
- **Максимальная влажность:** 70%

### Что делает программа

| Компонент прошивки (C) | Python-аналог |
|---|---|
| Пин D15, `dht.readTemperature()` | Эмуляция `read_sensor()` |
| Кнопка на D4 (INPUT_PULLUP) | `is_any_key_pressed()` (Enter) |
| Зелёный/красный светодиод | `update_leds()` (вывод в терминал) |
| Суперцикл 100 мс | `superloop()` с `time.sleep(0.1)` |

### Запуск

**Напрямую (без Docker):**
```bash
python climate-monitor/climate_monitor.py
```

**В Docker:**
```bash
docker build -t iot-climate ./climate-monitor
docker run --rm iot-climate
```

## 💡 Динамическое освещение через MQTT

Распределённая система управления освещением: публикуются команды `'1'`
(вкл) / `'0'` (выкл) в MQTT-топик, а узел-подписчик (в оригинале ESP32,
здесь — Python) управляет нагрузкой.

В отличие от оригинальной прошивки, где пакеты MQTT формировались вручную
побайтово, Python использует стандартную библиотеку **paho-mqtt** — это
проще, надёжнее и нагляднее.

### Настройка через переменные окружения

Секреты и адреса не зашиты в код:

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `MQTT_HOST` | `mosquitto` | Адрес брокера |
| `MQTT_PORT` | `1883` | Порт брокера |
| `MQTT_USER` | *(пусто)* | Логин (если нужен) |
| `MQTT_PASS` | *(пусто)* | Пароль |
| `MQTT_TOPIC` | `lamp/cmd` | Топик команд |

### Запуск всего стенда (Docker Compose)

```bash
docker compose up --build
```

Стек поднимает три сервиса:
- `broker` — локальный MQTT-брокер Mosquitto (порт 1883);
- `node` — MQTT-узел освещения.

### Как проверить MQTT-узел

Отправьте команду в топик команд (например, через `mosquitto_pub`
внутри контейнера брокера):

```bash
docker exec iot-projects-broker-1 mosquitto_pub -h localhost -t lamp/cmd -m "1"
```

В логах `node` появится:
```
Пришла команда: 1
Статус: СВЕТ ВКЛЮЧЕН
```

## 🐳 Инфраструктура Docker

- **`python:3.12-slim`** — лёгкий базовый образ для обоих проектов.
- **`eclipse-mosquitto:2`** — локальный брокер (изолированный, только для

- Секреты вынесены в переменные окружения — **не коммитьте пароли**.
